# Sawt Aljazair V1.5.3

## Fixes and features
- Dedicated PostgreSQL bootstrap remains enabled through `prisma db push`; no reset/drop/force-reset is used.
- Added optional `phone` and `whatsapp` fields to `User`.
- Added `PATCH /me/profile` for editing display name, bio, wilaya, phone, WhatsApp and avatar image.
- Added `GET /users/:id` for profile retrieval (placed after `/users/search` to avoid route collision).
- Report creation now requires selecting a location on an interactive map.
- Added current-location button and manual map tap selection.
- Main map continues to show reported locations and opens report details from markers.
- Public report coordinates remain rounded to protect exact location privacy; exact coordinates are stored separately in the report.
- Added phone/WhatsApp contact actions to the user's profile.
