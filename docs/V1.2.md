## Core routes
### Auth
- POST `/auth/register`
- POST `/auth/login`
- GET `/me`

### Feed
- GET `/feed`
- POST `/posts`
- POST `/posts/:id/like`
- POST `/posts/:id/save`
- GET `/posts/:id/comments`
- POST `/posts/:id/comments`

### Reports
- GET `/reports`
- POST `/reports`
- GET `/reports/:id`
- PATCH `/reports/:id/status`
- POST `/reports/:id/evidence`
- GET `/reports/search`

### Lost & Found
- GET `/lost-found`
- POST `/lost-found`
- GET `/lost-found/matches/:id`

### Verification

### Admin

### Chat

## Privacy
- Anonymous reports do not expose reporter name in public feed.
- Public map coordinates are rounded/obfuscated.
- Exact coordinates remain stored server-side for authorized review.
- Media should be reviewed before public publication.
