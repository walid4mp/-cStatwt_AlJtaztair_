# إصلاح نشر صوت الجزائر والوسائط

## 1) قاعدة البيانات على Render
- افتح خدمة PostgreSQL المقصودة من Render وانسخ **Internal Database URL** كاملاً إذا كانت قاعدة البيانات والخدمة في نفس المنطقة/الحساب. لا تكتب اسم المضيف يدوياً ولا تستخدم معرّف قاعدة البيانات وحده.
- ضع الرابط كاملاً في Web Service > Environment باسم `DATABASE_URL`. يجب أن يبدأ عادةً بـ `postgresql://` ويتضمن المضيف والمنفذ واسم القاعدة وبيانات الدخول.
- تحقق أن قاعدة PostgreSQL في حالة Available/Available، وأن خدمة الويب وقاعدة البيانات في المنطقة المناسبة. الخطأ `P1001` يعني أن المضيف/المنفذ غير قابل للوصول، وليس خطأ في Flutter.
- `DEDICATED_DATABASE=true` فقط إذا كانت قاعدة البيانات مخصصة حصرياً لصوت الجزائر. إذا كانت قاعدة مشتركة، لا تفعّله ولا تشغّل `prisma db push` عليها. راجع استراتيجية الترحيل الآمن قبل النشر.

## 2) تخزين الصور والفيديوهات
Render filesystem ليس تخزيناً دائماً. أنشئ Bucket عام القراءة في Cloudflare R2 (أو S3-compatible) ثم أضف في Render Environment:
- `S3_ENDPOINT`: عنوان S3 API الخاص بالحساب، وليس رابط صفحة لوحة Cloudflare.
- `S3_BUCKET`: اسم الـ bucket.
- `S3_REGION`: `auto` لـ R2.
- `S3_ACCESS_KEY` و`S3_SECRET_KEY`: مفاتيح API خاصة بالـ bucket.
- `S3_PUBLIC_BASE_URL`: رابط النطاق العام أو Custom Domain الذي يعرض ملفات الـ bucket.
- `PUBLIC_BASE_URL`: `https://cstatwt-aljtaztair.onrender.com` (اختياري للروابط العامة الأخرى).

لا تضع مفاتيح R2 أو `DATABASE_URL` داخل Flutter أو GitHub أو ملفات المشروع. لا تستخدم مفاتيح حساب Cloudflare العامة.

## 3) النشر والتحقق
بعد إضافة المتغيرات، نفّذ Manual Deploy. اختبر `https://cstatwt-aljtaztair.onrender.com/` ثم `/health`. يجب أن يعيد `/health` حالة قاعدة البيانات `ok`. جرّب رفع صورة صغيرة ثم فيديو MP4، وافتح الرابط الناتج من جهاز آخر.

## ملاحظات
- هذا الإصلاح يمنع إرجاع نجاح رفع في الإنتاج إذا لم يكن تخزين S3/R2 مضبوطاً؛ التخزين المحلي على Render قد يختفي بعد إعادة التشغيل.
- حد الرفع الافتراضي 100MB لكل ملف ويمكن تغييره بمتغير `MAX_UPLOAD_BYTES`.
- لا يمكن إصلاح `P1001` من داخل الكود إذا كانت `DATABASE_URL` تشير إلى مضيف غير صحيح أو قاعدة متوقفة؛ يجب نسخ الرابط الصحيح من لوحة Render.
