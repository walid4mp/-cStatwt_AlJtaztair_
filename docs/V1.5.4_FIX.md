# Sawt Aljazair V1.5.4

- Backend version bumped to 1.5.4.
- Added GET /version so the deployed API can be verified.
- Keeps dedicated PostgreSQL bootstrap via `prisma db push`; no reset/drop/force-reset.
- V1.5.3 profile and report/map routes remain included.

## Important deployment check
The Android app must point to the same Render API service that contains this backend. After deployment, opening the API root must return version 1.5.4, and `/version` must list `/me/profile` and `/reports`. If the app still shows `Route not found` or `public.Report does not exist`, it is connected to an older API service or the wrong DATABASE_URL.
